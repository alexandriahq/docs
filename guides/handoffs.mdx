Ambient can also turn recorded context into agent tasks, reusable Skills, and daily Reports. These features are secondary to the current recording rollout and may be hidden for your organization.

- **Agents** can prepare reviewed tasks from Activity context.
- **Skills** can capture reusable steps from completed work.
- **Reports** can summarize a day and, when separately permitted, be shared through approved destinations.
- **Integrations** and **Automations** have their own organization controls.

Disabling an optional feature does not delete existing data. Recording, redaction, Activity, intent maintenance, and Memory can continue independently.

<Note>
  If an optional page is absent from the sidebar, this normally reflects your organization's rollout configuration rather than an installation problem.
</Note>
