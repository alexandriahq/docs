Memory keeps durable notes derived from recorded work so useful context can persist beyond a single Activity thread.

## Use Memory

- Open **Memory** from the sidebar.
- Use List, Gallery, or Graph views when available in your rollout.
- Search for a project, person, workflow, decision, or recurring task.
- Open a memory to inspect its details and supporting context.
- Remove an incorrect memory; Ambient provides an undo opportunity after removal.

Memory is derived context, not a raw recording browser. Pausing recording prevents new source material from being captured during the pause, but does not delete existing Activity or Memory.

<Note>
  Feature availability is organization-specific. Memory can remain enabled even when Agents, Skills, and Reports are hidden.
</Note>
